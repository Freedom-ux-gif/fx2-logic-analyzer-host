# H2 软件使用

> 这份手册写给拿到这套东西的**用户**，不是写给它的人。
> 你不需要懂原理，只要知道：双击哪个、点什么按钮、文件存哪、出问题怎么办。
> 全文按「你正常使用的一天」来组织：先装好看到波形，再认识界面，然后完成几件常做的事，最后查漏补缺。

---

## 0. 三十秒上手

赶时间的话，照这五步走，绝大多数人到这里就够了：

1. 把逻辑分析仪插到电脑 USB 口。
2. 先双击一次 `Logic.exe`，等界面上出现设备名字，然后**关掉它**。
3. 双击 `13_web\dist_app\LogicWeb.exe`（推荐这个，功能最全）。
4. 浏览器会自动打开，顶部徽章变成绿色「● 设备就绪」。
5. 选一个采样率、填时长，点右上角【▶ 开始采集】，波形就出来了。

看到波形后，数据已经自动存到 `文档\LogicCapture\` 目录，不用你另存。
后面各章是把这五步展开，并告诉你每一步「应该看到什么、没看到该怎么办」。

> 备选：如果双击 exe 打不开，可以双击 `13_web\start.bat` 用源码方式启动，界面完全一样。
> 另有一个老版 `11_pack\dist\LogicScope.exe`（24 MB），界面是旧样式，只作备用，新用户不用它。

## 1. 第一次使用（从零到看到波形）

### 1.1 步骤

按号做，每一步后面都写了「预期看到什么」。看到的不一样，翻到 1.2 节对照排查。

1. **插上设备。** 用 USB 线把逻辑分析仪接到电脑。
   - 预期看到什么：电脑有插入提示音；设备指示灯亮。
2. **启动一次 `Logic.exe`。** 找到官方软件 `Logic.exe`，双击打开，等它识别出设备（界面上出现设备名称），再把它关闭。
   - 预期看到什么：官方软件里能看到设备名 —— 这说明电脑已经认识这块板子了。
   - 这一步绝对不能跳，原因见 1.3 节。
3. **双击 `LogicWeb.exe`。** 路径是 `13_web\dist_app\LogicWeb.exe`。
   - 预期看到什么：先弹出一个黑色命令行小窗口（正常，别关），几秒后浏览器自动打开网页界面。黑窗口是服务在后台跑，最小化即可，关掉它网页就失效了。
4. **看浏览器界面。** 浏览器打开的是本机地址（形如 `http://127.0.0.1:8421`），页面标题「逻辑分析仪」，左上角有品牌名「逻辑分析仪 · 8 通道」。
   - 预期看到什么：波形区中间有一行灰字「尚无数据 · 点击「开始采集」获取波形」。
5. **确认顶部徽章是绿色「● 设备就绪」。** 徽章在品牌名右边。
   - 预期看到什么：绿色圆点 + "设备就绪"四个字。刚打开时可能显示"检测中"，等几秒会自己变。
6. **选采样率、填时长。** 顶部「采样率」下拉框默认是 1 MHz，共 10 档可选；「时长 (s)」输入框默认是 1 秒，可填 0.01 到 30。不知道选什么就照第 6 章的表来。
   - 预期看到什么：下拉框里能看到 24 MHz / 16 MHz / 12 MHz / 8 MHz / 4 MHz / 2 MHz / 1 MHz / 500 kHz / 250 kHz / 200 kHz 这十档。
7. **点右上角【▶ 开始采集】。** 按钮在时长输入框右边。采集过程中顶部会出现进度条，徽章变成「● 采集中」，右边的【■ 停止】按钮变为可用。
   - 预期看到什么：进度条从 0% 走到 100%，几秒钟内结束。
8. **看结果。** 采集完成后，波形区出现 8 条通道的彩色方波；右侧「测量」栏列出各通道的频率等数据；底部状态栏显示样本数、耗时和保存路径。
   - 预期看到什么：底部「样本:」后面是一个具体数字（不是"样本: —"），「路径:」后面是 `Documents\LogicCapture\...` 的完整文件名。到此你就完成了第一次采集。

### 1.2 每步失败会看到什么

| 你看到的现象 | 大概原因 | 该怎么处理 |
|---|---|---|
| 徽章红色「● 设备未就绪」，下方黄色横幅写"设备未初始化，请先启动一次 Logic.exe" | 没跑第 2 步的初始化 | 关掉网页，先双击一次 `Logic.exe` 再关掉，然后刷新网页 |
| 徽章黄色「● 设备被占用」，横幅提示被其它程序占用 | 还有采集软件开着没关（最常见是老版 `LogicScope.exe` 或 `Logic.exe`） | 把所有采集软件都关掉，然后点一下那条黄色横幅，它会自己刷新状态 |
| 横幅提示"设备已就绪，但未检测到信号跳变" | 设备是好的，但信号线没接或没输出 | 检查信号线是不是接在 CH0 上，被测板子的输出有没有打开 |
| 徽章红色「● 后端未连接」 | 服务没起来，或被你关了 | 重新双击 `LogicWeb.exe`；那个黑色小窗口别关 |
| 点【▶ 开始采集】没反应，按钮是灰的 | 按钮被禁用，说明设备状态不对 | 先看徽章颜色，按上面对应行处理；徽章变绿后按钮会自动恢复 |
| 浏览器没自动打开 | 被系统拦截或默认浏览器异常 | 自己打开浏览器，手动输入控制台窗口里打印的地址，一般是 `http://127.0.0.1:8421` |

### 1.3 为什么必须先跑一次 Logic.exe

官方软件会给设备下发配置，把端点表从 6 个改成标准的 4 个（含数据端点 0x82）。没有这一步，我们的网页软件读不到数据端点，就采不到任何数据。

### 2.2 各区域说明

**顶部工具栏**
- 品牌区：显示「逻辑分析仪」和「Logic Analyzer · 8 通道」，只是标识，点不动。
- 设备徽章：就是那个带圆点的小标签，颜色代表设备状态 —— 绿色「设备就绪」可以采集，黄色「设备被占用」要关别的软件，红色「设备未就绪」要先跑 `Logic.exe`，蓝色/其它「采集中」表示正在干活。鼠标停在徽章上还能看到端点信息和版本号。
- 采样率下拉框 `采样率`：10 档可选，默认 1 MHz。选多快见第 6 章。
- 时长输入框 `时长 (s)`：想采几秒就填几，最小 0.01 秒，最大 30 秒，默认 1。
- 【▶ 开始采集】：采集按钮，设备没就绪时是灰的。
- 【■ 停止】：采集过程中可点，用来提前结束（提示已发出，当前这次采集完成后返回）。
- 【◐ 主题】：点一下在深色/浅色之间切换，选择会被记住，下次打开还是你上回选的样子。

**黄色提示横幅**
只在有问题时出现，横幅上的文字会直接告诉你哪里不对。设备被占用时，这条横幅还能点，点了就重新检查一遍设备状态。

**波形区（左侧大块）**
- 标题行有四个控件：
  - `[ ]触发采集`：勾上后展开触发条件表单，用来"等到某个事件出现才开始抓"，见 3.2 节。
  - 【⚙ 协议解码】：点一下在底部弹出/收起解码抽屉。
  - 【⟲ 全览】：点一下把缩放过的波形恢复到完整范围。
- 波形画布：8 条通道从上到下排列，每条左边标着 CH0~CH7 和颜色。鼠标在画布上的各种操作见 2.3 节。
- 时间轴：在波形底部约 30px 高的一细条，刻度会根据当前缩放自动在 ns、µs、ms、s 之间切换；左下角显示 `Δt=xxx`，表示你放的两个光标之间的时间差。
- 画布下方的灰色小字是一行操作提示：滚轮缩放、右键/空格拖动平移、左键放置光标、双击复位。

**侧栏（右侧）**
- 「通道」区：8 行，每行一个通道。行首复选框控制这条通道显不显示（取消勾选就藏起来）；中间 `CHn` 文字是通道名，颜色就是它在波形里的颜色；旁边的小色块可以点开颜色选择器，改这条通道的颜色。
- 「测量」区：采集后，每个通道会列出边沿数、频率、占空比、高电平占比、最小脉宽、最大脉宽。如果某通道一直是恒定电平，会直接显示「恒定高电平」或「恒定低电平」，不硬算频率。没采集时这里显示"采集后显示测量结果"。

**解码抽屉（底部，按需弹出）**
- 「协议」下拉框：UART / I2C / SPI / CAN 四种。
- 参数区：跟着协议变。选 I2C 出现"SCL 通道""SDA 通道"两个下拉；选 UART 出现 RX 通道、波特率、校验、停止位；选 SPI 出现 SCK / MOSI / CS 通道和 CPOL、CPHA；选 CAN 出现 CAN 通道、波特率、采样点。
- 【解码】按钮：参数填好后点它，结果出现在右边表格。
- 结果表格：列名是 #、类型、起始样本、时间、内容。超过 500 行会截断显示。**点表格里任意一行，波形上的光标会跳到那条记录对应的位置**，方便你回去看那段波形。

**底部状态栏**
- `样本:` 本次采集的样本数；`时长:` 采集耗时；`视图:` 当前缩放范围；`光标:` 当前光标所在样本；`路径:` 本次数据保存的完整路径。
- 【📁 打开文件夹】：采集完成后变可用，点一下直接用文件管理器打开数据目录。
- 三个导出按钮：【导出 CSV】【导出 VCD】【导出二进制】，位置在"打开文件夹"左边，采集完成前是灰的。

## 3. 四个核心工作流

### 3.1 采一段信号（最常用）

- **目的**：把被测板子这段时间里 8 个通道的高低电平录下来，看到波形并量出频率。
- **步骤**：
  1. 确认徽章是绿色「设备就绪」。
  2. 顶部选采样率（不确定就照第 6 章选），填时长。
  3. 点【▶ 开始采集】。
  4. 等进度条走完。
  5. 用滚轮放大你关心的那一段，左键单击放光标，看底部 `Δt` 读数。
  6. 看右侧「测量」栏读各通道频率、占空比等。
- **预期结果**：波形清晰可见，底部样本数非 0，测量栏有数字，数据已自动存盘。

### 3.2 触发采集

- **目的**：信号里只偶尔出现某个特定事件（比如某个下降沿），你想抓住它前后那一小段，而不是盲采一大堆。
- **步骤**：
  1. 点波形区标题行的 `[ ]触发采集` 复选框，勾选后下面展开一个条件表单。
  2. 「类型」下拉：选你要等的事件，共六种 —— 上升沿、下降沿、双边沿、高电平、低电平、脉宽。
  3. 「通道」下拉：选事件出现在哪条线（CH0~CH7）。
  4. 「参数」输入框：只有选「脉宽」时才需要填，填的是样本数；其它类型留 0 即可。
  5. 「预触发比例」输入框：填 0 到 1 之间的小数，默认 0.5。它表示"触发点之前的波形占整段的比例"，0.5 就是触发点前后各占一半，方便你看到事件发生前发生了什么。
  6. 照常选采样率、填时长，点【▶ 开始采集】。
- **预期结果**：软件一直等到条件满足才抓取；采完后波形会围绕那个事件展开，你可以用滚轮和光标细看触发点附近。
- 小提示：如果等了很久都没采到，多半是触发条件没出现 —— 换条通道或换个触发类型试试。

### 3.3 协议解码（以 I2C 为例）

- **目的**：把波形里那些方波翻译成看得懂的字节内容，比如 I2C 的地址和数据。
- **步骤**：
  1. 先按 3.1 采一段包含 I2C 信号的波形。
  2. 点【⚙ 协议解码】，窗口底部弹出解码抽屉。
  3. 「协议」下拉选 `I2C`。
  4. 参数区出现两个下拉：「SCL 通道」选接时钟线的通道，「SDA 通道」选接数据线的通道。**这两个不能选成同一个**，否则会弹提示让你重选。
  5. 点【解码】按钮。
  6. 右边表格列出解出来的每一帧：序号、类型、起始样本、时间、内容。
  7. 点表格里任意一行，波形上的光标会跳到那一帧的起点。
- **预期结果**：表格里是清晰的一行行记录，点行能定位波形，不用自己对高低电平数 bit。
- 其它协议同理：UART 要填 RX 通道、波特率、校验、停止位；SPI 要填 SCK / MOSI / CS 通道和 CPOL、CPHA；CAN 要填通道、波特率、采样点。
- 注意：表格最多显示 500 行，超出的部分被截断，但前面的记录都完整可用。

### 3.4 导出数据

- **目的**：把这次采集交给别的工具，或发给同事。
- **步骤**：采集完成后，底部【导出 CSV】【导出 VCD】【导出二进制】三个按钮会变亮；点其中任意一个，文件就存到 `文档\LogicCapture\` 目录。
- **三种格式的区别**：

| 格式 | 是什么 | 什么时候用 |
|---|---|---|
| 导出 CSV | 只记录电平发生变化的那些点（变化点模式），是纯文本表格 | 想用 Excel / WPS 打开看，或做简单统计；最通用 |
| 导出 VCD | 一种标准的波形交换格式 | 要导入到其它仿真/EDA 工具里继续分析 |
| 导出二进制 | 和原始采集一样的裸字节 `.bin`，每字节代表 8 个通道 | 要自己用程序处理，或原样留档，信息最完整 |

- 小提示：导出只带上当前显示（勾选）的通道，不显示的通道不会写进 CSV / VCD。想全导就把侧栏 8 个通道都勾上。

## 4. 文件在哪

### 4.1 目录与命名

所有采集和导出的文件都自动放在同一个目录：

```
C:\Users\<用户名>\Documents\LogicCapture\
```

也就是「文档\LogicCapture\」。换成你自己的电脑就是 `C:\Users\你的用户名\Documents\LogicCapture\`。

文件名规则是 `capture_YYYYmmdd_HHMMSS_<采样率>.bin`，例如：

```
capture_20261125_123456_1MHz.bin
```

读起来就是：2026 年 11 月 25 日 12 点 34 分 56 秒采的，采样率 1 MHz。采样率写在名字里，是为了你以后打开文件时还知道当时用的速度。

### 4.2 两种打开方式

- **方式一（推荐）**：采集完成后，直接点底部状态栏的【📁 打开文件夹】按钮，文件管理器会打开这个目录，最新文件就在里面。
- **方式二（手动）**：自己打开「此电脑 → 文档 → LogicCapture」，或在文件管理器地址栏粘贴上面的完整路径回车。

### 4.3 文件格式

`.bin` 是**裸字节**文件：每一个字节存一个时间点的采样值，字节里的 8 个二进制位分别对应 CH0~CH7（CHn 对应 bit n，1 表示高电平、0 表示低电平）。

这种文件本身不带采样率信息，所以：

- 自己解析时，必须同时知道当时用的采样率，才能算出每个点之间的时间间隔（间隔 = 1 ÷ 采样率）。这就是为什么文件名里带了采样率。
- 要把它发给别人分析，请**一并告诉对方两件事**：
  1. 这次采集用的采样率（比如 1 MHz）；
  2. 通道映射，也就是哪根信号线接到了哪个通道（CHn → bit n），最好把"SCL 接 CH0、SDA 接 CH1"这种对应关系也写上。

对方有了这两项，就能把字节流还原成正确的波形。

## 5. 常见问题 FAQ

**1. 双击 exe 没反应，黑框一闪就没了**
- 现象：双击 `LogicWeb.exe` 后什么也没留下。
- 原因：多半是上次的服务还占着端口，或程序启动失败被系统关掉。
- 解决：先确认没有重复的 exe 在跑（任务管理器里看），再双击一次；还不行就改用 `13_web\start.bat` 启动，窗口里会留下报错信息方便排查。

**2. 浏览器没自动打开**
- 现象：黑窗口在，但浏览器没弹出页面。
- 原因：默认浏览器设置异常，或弹窗被拦截。
- 解决：自己打开浏览器，在地址栏输入黑窗口里打印的地址（一般是 `http://127.0.0.1:8421`），回车即可。

**3. 端口被占用**
- 现象：日志里提到端口 8421 被占。
- 原因：8421 已经被别的程序用了。
- 解决：不用管 —— 软件会自动从 8421 往后试到 8430，用黑窗口里实际打印的那个地址访问就行。

**4. 采集到 0 字节 / 样本数是 0**
- 现象：采完底部「样本: 0」或波形区是空的。
- 原因：设备没初始化（缺 0x82 端点），或设备被占用。
- 解决：关掉网页，先跑一次 `Logic.exe` 再关掉，刷新页面重试；确认其它采集软件都关了。

**5. 波形全是一条直线**
- 现象：8 条通道都是平的，没有跳变。
- 原因：信号线没接好，或被测板子没输出。
- 解决：看顶部黄条是不是提示"未检测到信号跳变"；把信号线接到 CH0，确认被测设备已上电并开启输出，再采一次。

**6. 频率测量显示 0**
- 现象：某通道电平在变，但「测量」栏频率是 0。
- 原因：这条通道是恒定高/低电平（恒定电平不算频率），或采样率太低采不到边沿。
- 解决：恒定电平属正常，界面会显示「恒定高电平/低电平」；若确实在跳变，按第 6 章提高采样率再采。

**7. 解码解出大量帧错误**
- 现象：表格里全是错误帧，内容对不上。
- 原因：协议参数填错，最常见是波特率/采样点不对，或 SCL、SDA 接反。
- 解决：核对 UART 波特率、CAN 波特率是否和被测设备一致；I2C 确认 SCL 接时钟、SDA 接数据且不是同一个通道；提高采样率后再解。

**8. 导出的 CSV 打不开 / 中文乱码**
- 现象：双击 CSV 打不开，或用记事本打开中文乱码。
- 原因：CSV 是文本表格，不同软件对编码和分隔符的支持不一样。
- 解决：优先用 Excel / WPS 打开；若要选编码，试 UTF-8。只是看波形变化点的话，用 VCD 更省事。

**9. 杀毒软件报警**
- 现象：双击 exe 时杀毒软件提示风险。
- 原因：单文件 exe 的打包方式常被误判，属于常见误报。
- 解决：确认文件来自这套工具目录后，选择"允许/添加信任"，之后就不会再拦。

**10. exe 启动慢**
- 现象：双击后要等几秒甚至十几秒才出界面。
- 原因：单文件 exe 首次运行要先把自己解压到临时目录（约 3–8 秒），首次之后会快一些。
- 解决：耐心等，看到黑窗口说明它正在工作，别急着重复双击。

## 6. 采样率选择指南

基本原则：**采样率至少是被测信号最高频率的 2 倍，实际要留余量，取 5～10 倍更稳**。测低速信号别用太高的采样率（数据量大、文件也大），测高速信号则绝不能低于下限。

| 要测什么信号 | 建议采样率 | 为什么 |
|---|---|---|
| 按键、开关、GPIO 翻转（几 Hz～几 kHz） | 200 kHz / 500 kHz | 边沿很慢，低速档就够，文件小 |
| UART 串口 9600 波特率 | 至少 100 kHz（选 200 kHz 或 500 kHz） | 每位约 104 µs，需足够多点还原一位 |
| UART 串口 115200 波特率 | 1 MHz 或 2 MHz | 每位约 8.7 µs，低采样率会采歪 |
| I2C 标准模式 100 kHz | 1 MHz 或 2 MHz | 每个时钟周期约 10 µs，取 10 倍余量 |
| I2C 快速模式 400 kHz | 至少 2 MHz | 周期约 2.5 µs，低于此边沿会不准 |
| SPI 1 MHz | 4 MHz 或 8 MHz | 时钟快，需要多倍采样看同步边沿 |
| SPI 10 MHz | 24 MHz（用最高档） | 只有最高档才够 2 倍以上，否则数据全错 |
| 脉宽 / 频率精确测量 | 按信号频率取 10 倍以上 | 采得越密，边沿位置越准，Δt 读数越可信 |

采样率一共十档：24 MHz、16 MHz、12 MHz、8 MHz、4 MHz、2 MHz、1 MHz（默认）、500 kHz、250 kHz、200 kHz。拿不准就先选高一档，采完觉得数据太大再降。
