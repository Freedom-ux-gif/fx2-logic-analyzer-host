# 逻辑分析仪 · 自研上位机（10_gui）

双击可用的中文采集与查看界面。打开 → 选采样率 → 点开始 → 出波形 → 能导出。

## 怎么用

启动命令（在本目录下）：

```
python run_gui.py
```

五步操作流程：

1. 打开程序后，在右上角「采样率」下拉框选择速率（默认 4 MHz）。
2. 在「时长(秒)」输入采集时长，默认 2 秒，可填 0.1~30。
3. 点绿色【开始采集】按钮，等待进度到 100%，状态栏显示「完成 N 样本」。
4. 波形区自动显示 CH0~CH7 八条通道；可滚轮缩放、右键拖动平移、左键打光标。
5. 点【导出 CSV】或【导出 VCD】保存数据；或切到「协议解码」页解码 UART/I2C/SPI。

无信号时波形全为高电平是正常的（输入端内部上拉），程序不会因此出错。

也可以点【打开文件】回放本地 `.bin` 原始采样数据：文件名含 `_8m`、`_4m`、`_500k` 等提示时会自动猜采样率，否则按当前下拉框值解读，并在状态栏提示。

## 界面说明

**顶部工具栏**

- 采样率下拉框：10 档速率（24M/16M/12M/8M/4M/2M/1M/500k/250k/200k）。
- 时长(秒)：采集时长输入框，0.1~30 秒。
- 【开始采集】（绿色）：按当前速率和时长采集，后台线程执行，不卡界面。
- 【停止】：采集中可点击停止；未采集时禁用。
- 【打开文件】：选择 `.bin` 文件回放。
- 【导出 CSV】【导出 VCD】：把当前数据导出，无数据时禁用。
- 【适应窗口】：恢复波形全览。
- 右侧状态标签：显示「未连接 / 采集中 45% / 完成 8,060,928 样本 / 采集失败」。

**波形区（「波形」标签页）**

- 8 条横向通道带，左侧固定 60px 显示 `CH0`~`CH7` 及该通道摘要（频率或「恒高」「恒低」）。
- 8 个固定高区分度颜色；每像素列同时有高有低时画竖线，否则画水平段。
- 鼠标滚轮：以光标位置为中心缩放。
- 右键拖动：水平平移。
- 左键点击：画竖直光标线，底部状态栏显示样本号、时间和各通道电平。

**协议解码（「协议解码」标签页）**

- 协议下拉：UART / I2C / SPI，切换后参数区自动变化。
- UART：通道 0~7、波特率（常用值可手输）、校验（无/偶/奇）、停止位（1/2）。
- I2C：SCL 通道、SDA 通道。
- SPI：SCK、MOSI、CS（可空）、CPOL、CPHA。
- 【开始解码】：后台线程解码，完成后填入下方表格（列：# / 类型 / 起始样本 / 时间 / 内容）；无数据时禁用。
- 【清空结果】：清空解码表格。

**底部状态栏**

- 总样本数 / 实际时长 / 光标位置（样本号 + 时间 + CH0~CH7 电平）。

## 已知限制

- **采集使用 3 个并发读线程**（`cv.capture_timed(..., n_readers=3)`）：实测 4 MHz 约 100% 达成（4 MHz/1s ≈ 4,194,304 字节），单读线程在 4 MHz 只能拿到约 5%，曾测到 12 MHz 仍可能不到 100%。状态栏的进度按经过时间线性推进，完成后不再单独显示达成率。
- 未接信号时所有通道显示高电平，这是内部上拉导致的正常现象，不是故障。
- 通道映射是 **CHn → bitn**（CH0=bit0，…，CH7=bit7），与 sigrok 文档描述的「CH1 在 MSB、CH8 在 LSB」**相反**，这是本机克隆板实测结论。
- 未做触发采集：只能采集固定时长，不能按边沿/条件触发。
- 停止按钮只是复位界面状态：`cv.capture()` 内部 `sleep(seconds)` 无法真正中断，底层读线程会自然结束。
- 解码器源自 `09_app`，通道编号已统一为 **0..7 直接对应 bit0..bit7**（8 兼容旧调用），界面 CH0..CH7 原样透传，不做任何重映射。

## 为什么不用 PulseView

官方固件与本机克隆板不兼容，刷固件需要额外环境，故采用自研上位机直接驱动现有固件。
